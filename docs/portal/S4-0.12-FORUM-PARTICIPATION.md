# S4 / Portal 0.12 — Forum Participation

Status: **especificação pronta; depende de 0.11 Runtime PASS**

## Objetivo

Integrar participação real do Fórum à Minha Conta sem criar storage paralelo.

## Fontes

- tópicos: Forum/Node;
- respostas: Comment;
- autoria: Drupal User;
- estrutura: Forum/Taxonomy;
- listagem: Views;
- host: FORUM;
- shell: ACCOUNT.

## Seções

Minha Conta deve expor:

- Meus tópicos;
- Minhas respostas;
- links para conteúdo no FORUM;
- empty states;
- paginação/filtros quando úteis.

## Views primeiro

Preferir Views com filtro pelo usuário atual.

Não implementar EntityQuery custom se View resolve a mesma consulta com access e
cache adequados.

## Presenter

Portal pode adaptar cada linha para:

- title;
- tipo tópico/resposta;
- fórum;
- data;
- status publicado quando permitido;
- URL cross-domain;
- cache metadata.

Não passar Node/Comment inteiro para SDC.

## Design System

Contratos candidatos:

- forum-topic-card;
- participation-item;
- empty-state;
- content-list.

A implementação visual continua sob maturidade H4/H5 do tema.

## AJAX

Listagens são primeiro consumidor recomendado de Views AJAX.

Preservar:

- URL/filtros;
- pager;
- focus;
- loading/status;
- fallback normal.

Não acoplar à infraestrutura fetch/DOMParser antiga se View AJAX resolver.

## Access

Antes de metadata:

- Node access para tópico;
- Comment access para resposta;
- não expor comentário não publicado/moderado;
- User A não vê participação privada de User B.

## Cache

Considerar:

- user;
- user.permissions;
- user.node_grants:view;
- entity tags;
- Views cache;
- domain.

## Runtime gates

- usuário sem participação;
- tópicos próprios;
- respostas próprias;
- conteúdo removido/unpublished;
- moderation;
- User A/B;
- links ACCOUNT -> FORUM;
- shared session;
- AJAX pager/fallback;
- mobile/a11y.

## Fora do escopo

- Flag/follows;
- Comment Notify;
- busca global;
- aggregation Wiki/Cursos.
