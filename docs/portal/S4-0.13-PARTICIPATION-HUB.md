# S4 / Portal 0.13 — Participation Hub

Status: **especificação pronta; depende de 0.12 Runtime PASS**

## Objetivo

Criar na Minha Conta uma visão integrada das participações do usuário sem
unificar artificialmente as fontes de verdade.

## Fontes

- Fórum: Node + Comment + Forum/Taxonomy;
- Wiki: Node + Revisions;
- Cursos: Group membership + LMS status;
- comentários relevantes: Comment, quando realmente participativos.

## Arquitetura

```text
Forum adapter ----+
Wiki adapter -----+--> ParticipationAggregator --> presenter --> ACCOUNT
LMS adapter ------+
```

O aggregator não persiste feed paralelo.

## Contrato comum

Cada item pode expor:

- source: forum|wiki|course;
- type;
- title;
- summary/status quando autorizado;
- timestamp relevante;
- URL canonical no purpose correto;
- action opcional;
- cache tags.

Ordenação pode ser feita após agregar listas já autorizadas.

## Escopo inicial

- últimos tópicos do usuário;
- últimas respostas;
- últimos verbetes/contribuições Wiki confiáveis;
- cursos ativos/concluídos relevantes;
- links para seções completas.

Não criar feed infinito.

## Design System

Contratos candidatos:

- participation-card;
- activity-list;
- source/status label;
- empty-state.

A origem deve ser semanticamente identificável sem depender de cor apenas.

## AJAX

O Hub pode carregar uma lista inicial no servidor.

Filtros por origem/pager:

- preferir Views AJAX quando cada fonte for View;
- evitar endpoint JSON próprio apenas para o Hub;
- HTMX só depois do padrão 0.15 estar validado.

## Access/cache

Cada adapter aplica access antes de retornar item.

O aggregator nunca recebe item proibido para filtrar depois.

Cache deve combinar dependencies das fontes e variar por usuário/permissões.

## Gates Runtime

- usuário sem atividade;
- somente Fórum;
- somente Wiki;
- somente Cursos;
- múltiplas fontes;
- conteúdo removido/unpublished;
- User A/B;
- URLs por Domain;
- ordenação;
- cache;
- AJAX/fallback;
- mobile/a11y.

## Fora do escopo

- notifications;
- bookmarks/follows;
- ranking/gamification;
- storage de activity feed;
- analytics comportamental com PII.
