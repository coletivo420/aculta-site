# S4 / Portal 0.11 — Forum Foundation

Status: **especificação pronta; Runtime required para implementação**

## Dependência

Planejada:

`drupal/forum:^1.1`

Baseline pesquisado em 2026-10-06:

- stable 1.1.3;
- Drupal ^11 || ^12;
- security advisory coverage;
- Forum usa Node + Taxonomy + Comment (e dependências Core próprias).

Não adicionar Composer nesta fase documental.

## Fonte de verdade

- tópico: Node do Forum;
- resposta: Comment;
- estrutura: Taxonomy/Forum;
- autoria/access: Drupal;
- sessão: Drupal User;
- host/purpose: Domain.

Nenhuma entity Topic/Reply custom.

## Domain

Planejado:

- purpose: `forum`;
- Domain ID: `forum_aculta_org`;
- produção: `forum.aculta.org`;
- Homelab: `forum.aculta.toca.net.br`.

Ativação apenas no Runtime.
