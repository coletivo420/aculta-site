# Histórico institucional de implementação

durante fases anteriores do projeto.

**Histórico / não normativo.**

Os arquivos podem citar paths, nomes técnicos ou estados antigos, inclusive o
tema histórico `aculta`. Eles servem como evidência de execução e contexto,
não como instrução corrente.
